03 Fondamentaux Tech Débutant

Premier langage : Python

On écrit du vrai code ! Python est le langage idéal pour débuter : lisible, proche de l'anglais, et utilisé partout (web, data, IA, automatisation). Beaucoup de pratique ici.

Un langage, c'est quoi ? Une façon d'écrire des instructions que l'ordinateur exécute, dans l'ordre, de haut en bas. Python se lit presque comme de l'anglais — c'est pour ça qu'on le choisit pour commencer. Garde ton terminal et un éditeur de texte ouverts, et tape tout toi-même : on n'apprend à coder qu'en codant.

Installer & lancer Python

Installe Python depuis python.org, puis vérifie :

terminal
python --version     # ou python3 --version selon ton système
# -> Python 3.12.x

Crée un fichier hello.py avec cette ligne, puis lance-le :

hello.py
print("Bonjour le monde !")
terminal
python hello.py
# -> Bonjour le monde !

print(...) affiche du texte à l'écran. Félicitations, tu viens d'exécuter ton premier programme ! 🎉

Variables & types

Une variable est une boîte étiquetée qui contient une valeur. On la crée avec = :

python
nom = "Alice"        # texte (str)
age = 30             # entier (int)
taille = 1.68        # décimal (float)
majeur = True        # booléen (bool) : True ou False

print(nom, "a", age, "ans")
# On peut insérer des variables dans du texte avec une f-string :
print(f"{nom} mesure {taille} m")
# -> Alice mesure 1.68 m

Les 4 types de base : str (texte), int (nombre entier), float (nombre à virgule), bool (vrai/faux).

Les conditions : if / elif / else

Faire des choix selon une situation. Attention : le bloc conditionnel est indenté (décalé de 4 espaces) — en Python, l'indentation fait partie du code !

python
age = 20

if age < 18:
    print("Mineur")
elif age < 65:
    print("Adulte")
else:
    print("Senior")
# -> Adulte

Les comparaisons : == (égal), != (différent), <, >, <=, >=. On combine avec and, or, not.

Pair ou impair Exercice

Écris un programme qui dit si un nombre est pair ou impair. Indice : % donne le reste d'une division (10 % 2 vaut 0).

python — solution
nombre = 7
if nombre % 2 == 0:
    print("pair")
else:
    print("impair")
# -> impair

Les boucles : for & while

Répéter des instructions sans se répéter. for parcourt une série ; while répète tant qu'une condition est vraie.

python
# range(1, 4) produit 1, 2, 3 (la borne de fin est exclue)
for i in range(1, 4):
    print(f"Tour numéro {i}")
# -> Tour numéro 1 / 2 / 3

# while : on répète tant que la condition tient
compteur = 0
while compteur < 3:
    print("ping")
    compteur = compteur + 1     # ne pas oublier, sinon boucle infinie !
Compter jusqu'à 5 Exercice

Affiche les nombres de 1 à 5, chacun sur sa ligne.

python — solution
for n in range(1, 6):
    print(n)
# -> 1 2 3 4 5 (un par ligne)

Les fonctions

Une fonction est un bloc de code réutilisable qu'on nomme, pour ne pas se répéter. On la définit avec def, elle peut recevoir des arguments et renvoyer un résultat avec return.

python
def saluer(nom):
    return f"Bonjour {nom} !"

# on "appelle" la fonction :
message = saluer("Alice")
print(message)          # -> Bonjour Alice !
print(saluer("Bob"))    # -> Bonjour Bob !
Une fonction qui additionne Exercice
python — solution
def addition(a, b):
    return a + b

print(addition(3, 5))    # -> 8

Listes & dictionnaires

Deux façons de stocker plusieurs valeurs :

  • Une liste [ ] — une suite ordonnée (on accède par position, en commençant à 0).
  • Un dictionnaire { } — des paires clé → valeur (on accède par le nom de la clé).
python
# Liste
fruits = ["pomme", "banane", "kiwi"]
print(fruits[0])          # -> pomme  (le premier, index 0)
fruits.append("mangue")   # ajoute à la fin
print(len(fruits))        # -> 4  (len = longueur)

for fruit in fruits:      # on parcourt la liste
    print(fruit)

# Dictionnaire
personne = {"nom": "Alice", "age": 30}
print(personne["nom"])    # -> Alice
personne["ville"] = "Paris"   # ajoute une paire

La Programmation Orientée Objet (POO)

Jusqu'ici, les données (variables) et les actions (fonctions) vivaient séparément. La POO permet de les regrouper dans un même « objet ». L'analogie : une classe est un moule (le plan), et un objet est ce qu'on fabrique avec (un exemplaire). Avec un moule à gâteau (la classe), on fabrique autant de gâteaux qu'on veut (les objets), chacun avec ses propres caractéristiques.

  • Une classe décrit un type de chose : ses attributs (ses données) et ses méthodes (ce qu'elle sait faire).
  • Un objet (ou instance) est un exemplaire concret créé à partir de la classe.
python
class Chien:
    # __init__ est le "constructeur" : il s'exécute à la création d'un objet
    def __init__(self, nom, age):
        self.nom = nom        # attribut : une donnée propre à CE chien
        self.age = age

    # une méthode : une action que l'objet sait faire
    def aboyer(self):
        return f"{self.nom} dit : Wouf !"

# On crée deux objets (deux instances) à partir du moule Chien
rex = Chien("Rex", 3)
bella = Chien("Bella", 5)

print(rex.nom)          # -> Rex                 (on lit un attribut)
print(rex.aboyer())     # -> Rex dit : Wouf !    (on appelle une méthode)
print(bella.aboyer())   # -> Bella dit : Wouf !
À quoi sert self ?

self représente l'objet lui-même — c'est ce qui permet à chaque chien de connaître son propre nom. Il est toujours le premier paramètre des méthodes, et Python le passe automatiquement quand on écrit rex.aboyer() : tu n'as jamais à le fournir toi-même.

Pourquoi c'est utile

La POO aide à organiser un programme qui grandit : au lieu d'une soupe de variables, on modélise des « choses » cohérentes (un utilisateur, une commande, un produit) qui portent leurs données et leur comportement. La plupart des bibliothèques Python que tu utiliseras (y compris pour notre mini-API au chapitre 6) sont construites en objets.

Une classe « CompteBancaire » Exercice

Crée une classe avec un solde, une méthode deposer(montant) et une méthode afficher().

python — solution
class CompteBancaire:
    def __init__(self, solde=0):     # solde de départ à 0 par défaut
        self.solde = solde

    def deposer(self, montant):
        self.solde = self.solde + montant

    def afficher(self):
        print(f"Solde : {self.solde} €")

compte = CompteBancaire()
compte.deposer(100)
compte.deposer(50)
compte.afficher()      # -> Solde : 150 €

Gérer les erreurs : try / except

Certaines opérations peuvent échouer (diviser par zéro, un fichier absent…). Plutôt que de faire planter le programme, on attrape l'erreur :

python
try:
    resultat = 10 / 0
except ZeroDivisionError:
    print("Oups, on ne divise pas par zéro !")
# -> Oups, on ne divise pas par zéro !

Lire & écrire un fichier

Un programme utile sait souvent lire ou sauvegarder des données. Le mot-clé with ouvre le fichier et le referme proprement tout seul :

python
# Écrire ("w" = write, écrase le fichier)
with open("journal.txt", "w") as f:
    f.write("Ma première ligne\n")

# Lire ("r" = read)
with open("journal.txt", "r") as f:
    contenu = f.read()
print(contenu)     # -> Ma première ligne

Ces bases suffisent déjà à écrire des programmes utiles — et au chapitre 6, on les assemblera pour construire une vraie mini-API. 💪

Erreurs fréquentes

Décoder les messages de Python
  • IndentationError — ton indentation est incohérente. Utilise toujours 4 espaces (jamais un mélange espaces/tabulations).
  • SyntaxError: expected ':' — tu as oublié le deux-points à la fin d'un if, for, def…
  • NameError: name 'x' is not defined — tu utilises une variable qui n'existe pas (faute de frappe, ou définie plus bas).
  • TypeError — tu mélanges des types incompatibles, ex. "age " + 30 (texte + nombre). Convertis : "age " + str(30).
  • Astuce : lis le message de bas en haut — la dernière ligne dit le type d'erreur, et le numéro de ligne t'indique où chercher.
